# SKIM Incoming · La Molina

Vídeo promocional procedural de **15 segundos**, **1920 × 1080**, **60 fps**, con música original sintetizada. Paisaje artístico inspirado en La Molina.

## Descargar

- [Vídeo MP4](SKIM.mp4): abre el archivo y pulsa **Download raw file** (flecha hacia abajo). Si aparece **View raw**, haz clic derecho y elige **Guardar enlace como…**.
- [Fuentes reproducibles y evidencias de revisión (ZIP)](SKIM_fuentes.zip).
- [Decisiones creativas, técnicas, revisión y tiempo real](film/DECISIONES.md).

El código editable también está en [film/](film/). Las instrucciones para regenerar imagen y música están en [film/README.md](film/README.md).

La revisión visual cubrió los 900 fotogramas exportados; la comprobación del audio fue técnica, sin escucha directa. El detalle de las verificaciones está en el ZIP y en DECISIONES.md.
